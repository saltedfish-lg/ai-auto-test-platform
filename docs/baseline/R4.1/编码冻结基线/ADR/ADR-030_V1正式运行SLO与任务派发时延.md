# ADR-030：V1正式运行SLO与任务派发时延

- 状态：ACCEPTED
- 发布：PDBR-2026.08.06-R3
- 决策来源：用户于2026-08-06确认PRD-NFR-001～003。

## 决策
1. V1生产控制面月度可用率不低于99.5%；提前公告的计划维护窗口不计入；开发、测试环境不纳入正式SLA。
2. 标准V1容量和正常网络下：普通查询P95≤500ms、P99≤1000ms；普通写入P95≤800ms、P99≤1500ms；异步命令受理P95≤300ms、P99≤800ms。文件传输、AI模型调用和浏览器执行使用专用指标。
3. 存在健康、已绑定、能力匹配的空闲Runner且无锁、租约、资源冲突时，从SCHEDULABLE到CLAIMED：P95≤3秒、P99≤10秒。

## 度量与证据
- API每类不少于10000个有效样本；任务派发不少于5000个有效样本。
- 使用服务端单调时钟，保留原始时序、聚合报告、环境快照和排除项清单。
- 未绑定真实证据时验收状态只能是SPECIFIED或EXECUTED_FAILED，不得标记PASSED。
