# ADR-021：模型供应商白名单与默认模型

- 状态：`INCORPORATED`
- 对应决策：`PEND-R3-004`
- 权威来源：`USER_SELECTED_IN_REPAIR_INSTRUCTION`
- 目标发布：`PDBR-2026.08.06-R3`
- 阻断 FULL_CODE_READY：`false`

## 决策

- V1 固定支持 `OpenAI`、`Anthropic`、`DeepSeek`、`Qwen`、`Doubao` 五个 Provider；不开放 Custom Provider 注册。
- `model_name` 使用 Provider 原生模型标识；平台不维护完整模型目录。
- Provider `base_url` 由平台预置，普通用户和公开 API 不得提交或修改任意 URL。
- 业务仅依赖 `ModelGateway`，正式调用路径为 `AI功能 -> ModelGateway -> LiteLLM Proxy -> Provider`，不得由前端或业务模块直连供应商 SDK。
- `AI_EXPLORATION` 在平台级最多绑定一个 effective default `ModelConfig`；当前不实现项目偏好、继承或 fallback。

## 兼容性与实施约束

- 不改变已确认的产品范围、Runner权威边界、四条AI/录制/执行路径和既有状态历史。
- 实现必须经由冻结端口、状态Owner、权限守卫、幂等键和不可变审计。
- 当前默认模型不得直接禁用；必须先解除绑定或原子切换到其他 `ACTIVE` 模型。
- Connection Test 是即时诊断行为，只返回结构化结果并写不可变审计，不持久化 `last_test_*`，也不改变 ModelConfig 生命周期。
- ModelConfig Secret 必须加密保存，且不得出现在 API 响应、前端回填、日志、审计或 Runtime Evidence 中。
- 若状态为待确认，本ADR仅作为候选设计，不得生成最终初始化种子或发布门禁通过证据。
