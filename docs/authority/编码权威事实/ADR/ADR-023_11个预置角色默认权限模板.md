# ADR-023：11个预置角色默认权限模板

- 状态：`INCORPORATED`
- 对应决策：`PEND-R3-006`
- 权威来源：`USER_APPROVED_RECOMMENDED_SCHEME`

## 正式决策

批准现有11个SYSTEM_PRESET角色及完整540条角色—权限映射作为V1初始化授权事实。SUPER_ADMIN仅允许绑定内置admin；其他角色必须受项目或平台范围、对象状态、独立敏感权限和不可变审计约束。默认权限模板以版本化初始化迁移发布，后续变更必须新增版本，不得静默覆盖历史。

## 实施约束

- 本决策为R2冻结事实，实施不得退回候选、待确认或隐式默认状态。
- 所有写操作必须通过权限守卫、状态Owner、幂等键和不可变审计。
- 任何偏离必须新增ADR和版本化迁移，不得静默改写本决策。

## 验收要求

- 机器契约、可读文档、初始化数据和验收闭包必须表达同一规则。
- 合同测试必须覆盖正常路径、越权路径、状态冲突、幂等重放和审计证据。
