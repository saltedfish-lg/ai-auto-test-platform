# ADR-025：用例与资产版本双人复核策略

- 状态：`INCORPORATED`
- 对应决策：`PEND-R3-008`
- 权威来源：`USER_APPROVED_RECOMMENDED_SCHEME`
- 生效发布：`PDBR-2026.08.06-R3`
- 阻断 FULL_CODE_READY：`false`

## 正式决策

普通资产由项目配置是否需要审核；AI探索和人工录制生成的候选版本在发布前必须由真实USER人工确认。共享资产、跨项目资产以及敏感账号/凭证资产必须双人复核，提交人和审核人必须是不同USER；SERVICE_ACCOUNT不得充当审核人；admin和SUPER_ADMIN不得静默绕过，任何例外均必须形成显式高风险操作和不可变审计。

## 实施约束

- 本决策为R2冻结事实，实施不得退回候选、待确认或隐式默认状态。
- 所有写操作必须通过权限守卫、状态Owner、幂等键和不可变审计。
- 任何偏离必须新增ADR和版本化迁移，不得静默改写本决策。

## 验收要求

- 机器契约、可读文档、初始化数据和验收闭包必须表达同一规则。
- 合同测试必须覆盖正常路径、越权路径、状态冲突、幂等重放和审计证据。
