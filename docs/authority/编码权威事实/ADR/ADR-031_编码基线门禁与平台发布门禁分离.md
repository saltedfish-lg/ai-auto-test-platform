# ADR-031：编码基线门禁与平台发布门禁分离

- 状态：ACCEPTED
- 发布：PDBR-2026.08.06-R4
- 日期：2026-08-06

## 决策

将门禁拆分为两层：

1. **CODE_BASELINE_READINESS**：决定是否允许Codex初始化工程和分阶段编码。包括事实源解析、状态、DDL静态语义、OpenAPI、事件、RBAC、验收规范、治理文件一致性及MySQL 8.4空库迁移/种子实跑。
2. **IMPLEMENTATION_RELEASE_READINESS**：决定已实现平台是否可发布。决策形成时的历史闭包为1691项；OBJ-085退役后当前验收数量以 `tools/current_facts.py#acceptance.count` 为准，并连同安全、性能、恢复、部署和制品生命周期证据共同判定。

真实平台验收证据不再作为“开始编码”的循环前置条件。当前环境无法执行MySQL 8.4运行门禁，因此R4状态为`READY_WITH_RUNTIME_DB_VALIDATION_PENDING`；平台未实现，发布门禁为`P1_AUTH_IMPLEMENTED_PENDING_RUNTIME_VALIDATION_FULL_PLATFORM_NOT_YET_EVALUATED`。
