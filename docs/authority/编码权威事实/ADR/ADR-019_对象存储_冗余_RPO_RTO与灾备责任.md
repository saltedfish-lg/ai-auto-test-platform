# ADR-019：对象存储、冗余、RPO/RTO与灾备责任

## 正式决策

采用S3兼容对象存储端口；本地或内网部署默认使用MinIO单实例并配置独立备份存储，生产环境允许替换为托管S3。元数据RPO不高于24小时、RTO不高于8小时；制品RPO不高于24小时、RTO不高于24小时；执行每日备份和季度恢复演练。平台建设及运维预算承担存储与备份成本，平台运维负责人和存储Owner共同承担备份、恢复演练和故障处置责任。

## 实施约束

- 本决策为R2冻结事实，实施不得退回候选、待确认或隐式默认状态。
- 所有写操作必须通过权限守卫、状态Owner、幂等键和不可变审计。
- 任何偏离必须新增ADR和版本化迁移，不得静默改写本决策。

## 验收要求
