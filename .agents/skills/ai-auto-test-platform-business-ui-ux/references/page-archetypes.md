# Page Archetypes for AI Auto Test Platform

## 1. Management Workspace

适用：项目、环境、业务终端、测试账号、测试数据资源等。

优先：高密度表格、筛选、状态、批量动作、详情抽屉/侧栏、可见数据范围。
避免：一对象一卡片的大面积卡片墙。

## 2. Authoring Workspace

适用：自然语言用例、结构化用例、模板、套件。

优先：树/列表 + 主编辑区 + 辅助上下文；步骤、变量、断言、版本状态可并行查看。
避免：把复杂编辑拆成大量弹窗。

## 3. AI Assisted Workspace

适用：AI页面探索、结构转换、人工录制、候选确认。

优先：浏览器/任务主工作区 + 步骤/时间线 + 候选/证据/定位器；明确AI进行中、等待人工、失败和可恢复checkpoint。
避免：只显示一个聊天框和“AI正在思考”。

## 4. Operational Monitoring

适用：执行中心、任务详情、Runner中心。

优先：实时状态、进度、当前对象、失败/异常、资源与Runner、最近心跳/租约、可干预动作。
避免：用总数KPI掩盖当前异常。

## 5. Diagnosis / Analysis

适用：报告中心、失败分析、日志、制品。

优先：失败优先、聚类/筛选、步骤证据、日志/截图/trace关联、重试结果、根执行事实与投影区分。
避免：先展示大量成功指标，失败信息藏在页面底部。

## 6. Governance / Configuration

适用：用户、角色、权限、模型、系统配置、审计策略。

优先：稳定表单/表格、差异确认、风险提示、审计信息、危险动作隔离。
避免：过度动效和装饰。

## 7. Monitoring / Logs

适用：技术健康、告警、审计日志、系统日志。

优先：过滤、时间范围、严重度、关联ID、实时/历史边界、钻取。
避免：为了视觉“简洁”隐藏关键列。

## 8. Authentication / Security Flow

适用：登录、首次改密、会话失效、安全确认。

优先：单一明确任务、错误恢复、凭证安全说明、焦点/键盘、无干扰。
允许适量品牌表现，但不得使用与业务无关的大量营销文案或装饰。
