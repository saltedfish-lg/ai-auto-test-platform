# Design System Rules

- 继续使用 Vue 3 + Element Plus，不另起一套UI框架；
- 优先定义/复用语义 token：surface、border、text、muted、primary、success、warning、danger、info；
- 状态色必须语义稳定，不能同一状态在不同页面随意换色；
- 间距、圆角、阴影使用有限级别，不逐组件自由发挥；
- 高密度工作台允许更紧凑的表格和控件；认证/表单页可以更舒展；
- 图标使用一致图标集，不用随机Unicode字符冒充图标；
- 组件抽象服务复用和一致性，不为减少代码行数创建无语义包装层；
- 优先响应桌面工程工作台，同时保证常见笔记本宽度不溢出；
- 动效仅用于状态变化、反馈和空间连续性，不做装饰性循环动画。
