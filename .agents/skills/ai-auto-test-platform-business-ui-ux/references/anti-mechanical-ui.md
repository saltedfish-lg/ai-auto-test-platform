# Anti-mechanical UI Rules

## 常见 AI 味

- 每页一个大号欢迎语；
- 英文大写 Eyebrow 作为固定装饰；
- 三到四个渐变 KPI Card；
- 所有 section 都是圆角卡片；
- 同一层级使用过多 Tag；
- 空洞图标、emoji、发光渐变；
- 表格上方堆满不分主次的按钮；
- 详情必须弹窗，编辑必须弹窗；
- 为“现代感”强行降低数据密度。

## 业务优先替代方案

- 首屏优先当前任务/异常/待处理，而非欢迎语；
- 用 section header、toolbar、split pane、tabs、detail panel 建立层级；
- KPI 只有在真的支持判断/行动时才出现；
- 状态使用文字 + 图标/颜色，颜色只做辅助；
- 危险动作放在明确的 danger 区或更多菜单，必要时二次确认；
- 高频动作靠近数据和当前上下文；
- 失败结果优先于成功统计；
- 复杂编辑采用持久工作区，而不是连续弹窗。

## 视觉方向

目标：企业级测试工程工作台。

关键词：克制、清晰、高密度、可扫描、状态明确、证据导向、工程感。

避免：营销落地页风格、游戏化、过度玻璃拟态、过强渐变、无业务意义的动画。
