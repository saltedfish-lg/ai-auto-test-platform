# Precision Loading

## 加载优先级

1. 目录和文件名；
2. 搜索命中行；
3. 符号签名和局部实现；
4. 调用者/被调用者；
5. 相关权威事实片段；
6. 必要时整文件；
7. 必要时整份契约。

## 允许整文件读取的情况

- 文件本身很短；
- 状态机/事务/生命周期跨多个函数，局部读取会失真；
- 组件模板和脚本强耦合；
- 配置/Schema 必须完整校验；
- Reviewer 需要验证全局不变量。

## 不应整文件读取的情况

- 只需确认一个类型定义；
- 只需确认一个 operationId；
- 只需确认单个 permission/status；
- 大型生成文件只需查一个符号；
- 大文档只需一个权威章节。

Token 节省来自减少无关正文，不来自减少必要证据。
